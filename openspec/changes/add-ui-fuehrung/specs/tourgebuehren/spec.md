## MODIFIED Requirements

### Requirement: Gebührenpflicht
Tourgebühren SHALL nur für Reservierungen entstehen, die als Tour gelten. Gebührenpflichtig SHALL jede Person an Bord sein: Skipper, Co-Skipper, Crew und Gäste.

#### Scenario: Keine Tour
- **WHEN** ein Boot für einige Stunden reserviert ist
- **THEN** entstehen keine Tourgebühren
